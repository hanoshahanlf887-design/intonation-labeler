# Examples

`synthetic_001.json` is a fully synthetic example that demonstrates the acoustic-feature input schema.

It does not contain original internship audio, private transcripts, or historical sample IDs.

To run live Gemini inference, provide your own `synthetic_001.wav` or another WAV file with the same stem as its JSON file. Demo / Dry Run mode can be used to exercise parsing, pairing, and export behavior without making Gemini API calls.
